# OCF Tools｜勞務報酬單產生器

以瀏覽器填寫所得人資料、試算報酬扣款，並預覽及列印勞務報酬單。採用 OCF 品牌配色，適用民國 115 年度（2026）給付資料。

## 主要功能

- 所得人資料：姓名、身分證／居留證／護照號碼、生日、戶籍地址與聯絡電話。
- 三種稅務身分：本國籍、外國籍（在台滿 183 天）、外國籍（在台未滿 183 天）。非本國籍必填生日。
- 申報類別：50、9A90、91、9B98、9A92、獎助學金及自行輸入。
- 自動試算所得稅、補充保費及實領金額，支援由希望實領金額反算給付總額。
- 自訂申報類別可自行輸入所得稅與補充保費；此模式不提供反算。
- 匯款資料包含銀行名稱／代碼、分行名稱／代碼、帳號及戶名，四個欄位均呈現在單據上。
- 給付方式提供銀行匯款及現金。
- 支援簽名圖片、手寫簽名與證明附件。
- 即時單據預覽、放大預覽及 A4 列印／另存 PDF。

預設申報類別為 **50 非固定薪資**；「帶入範例」會切換為 9A90，以呈現原有扣款範例。

## 使用方式

1. 填寫所得人資料。聯絡電話為必填；戶籍地址須包含鄰里，境外居住者填寫英文現居地址。
2. 依國籍與該年度在臺居留天數選擇稅務身分。
3. 如需匯款，填入銀行、分行、帳號與戶名。
4. 選擇申報類別，填寫給付日期、給付方式、勞務內容與金額。
5. 確認補充保費資格；需要時補充免扣原因或非居住者全月薪資總額。
6. 視需要加入簽名與證明附件。
7. 檢查報酬試算及單據預覽，再按「列印／另存 PDF」。

給付單位固定為財團法人開放文化基金會。簽章區的日期會依給付日期自動換算為民國年月日。

### 試用範例

按「帶入範例」可查看虛構資料：給付總額 30,000 元、所得稅 3,000 元、補充保費 633 元，實領 26,367 元。

範例證件號碼為 `DEMO-ID`，目前程式會阻止直接列印此範例。正式開立前，請將全部範例欄位替換為實際資料。

### PDF 與附件

- 在瀏覽器列印視窗中選擇「另存為 PDF」，紙張使用 A4 直式。
- 建議關閉瀏覽器頁首頁尾，並在儲存前檢查預覽的分頁、縮放與文字完整性。
- 簽名圖片支援 PNG、JPG、WebP，每張上限 5 MB。
- 證明附件最多 2 張，每張上限 5 MB，會附於單據後方。
- 簽章欄位可保留空白，列印後再以紙本簽署。

## 下載到本機使用（不需安裝）

1. 下載 ZIP 套件並完整解壓縮，不要直接在 ZIP 內開啟網頁。
2. 進入 `ocf-labor-receipt` 資料夾，再開啟 `docs` 資料夾。
3. 使用 Chrome、Edge 或 Safari 開啟 `index.html`。
4. 即可填寫資料、試算報酬、預覽單據，並透過「列印／另存 PDF」儲存結果。

此方式不需要上傳 GitHub，也不需要安裝 Python、Node.js 或其他套件。請保留 `docs` 內的所有檔案及 `assets` 資料夾，避免樣式、計算或 Logo 無法載入。日常填寫與試算不需要網路；開啟外部查核來源連結則需要網路。

**資料不會自動儲存。** 重新整理或關閉頁面前，請先列印或另存 PDF。內建範例資料僅供預覽，正式列印前須改成實際資料。

若瀏覽器對本機檔案有限制，或要進行程式開發，可改用下方的本機伺服器方式。

## 本機伺服器啟動（選用）

本專案使用原生 HTML、CSS 與 JavaScript，不需要安裝前端套件或執行建置。

在包含 `docs` 的專案根目錄執行：

```bash
python3 -m http.server 8000 --directory docs
```

開啟 <http://localhost:8000>。

## 檔案說明

| 路徑 | 用途 |
| --- | --- |
| `docs/index.html` | 頁面結構與輸入表單 |
| `docs/style.css` | OCF 品牌配色、響應式版面與列印樣式 |
| `docs/app.js` | 表單互動、資料驗證、簽名附件與單據產生 |
| `docs/calc.js` | 報酬、扣款與反算邏輯 |
| `docs/rules.js` | 頁面與單據共用的扣款規則說明 |
| `docs/assets/` | Logo 等靜態素材 |
| `checks/` | 計算與單據檢查程式 |

## 檢查方式

已安裝 Node.js 時，可在專案根目錄執行：

```bash
node checks/calculation.cjs
node checks/document.cjs
```

修改年度、門檻或扣款邏輯時，應同步檢查 `calc.js`、`rules.js`、`app.js` 的年度限制與相關檢查案例，並確認網頁及列印結果一致。

## 資料處理

所得人資料、銀行帳號、簽名與附件在目前瀏覽器中處理，程式不將表單資料傳送至伺服器，也不提供持久儲存。重新整理或關閉頁面後，填寫內容不會保留，請先完成列印或另存 PDF。

## 適用範圍

本工具協助填寫與試算，不代為提交扣繳申報。請依實際契約、所得性質及扣費資格確認適用方式；免扣繳不代表免稅。50 類別限兼職／非每月給付薪資，獎助學金選項限符合免稅條件的給付。完整限制與查核來源請參閱頁面下方的計算規則。

本 README 描述目前版本行為，不代表已重新查核各項稅務規定。使用其他年度資料前，請先更新相關規則與程式。


## 上傳 GitHub 與發布 GitHub Pages

1. 建立 GitHub 儲存庫，例如 `ocf-labor-receipt`。
2. 解壓縮套件並進入資料夾，使用「Add file → Upload files」上傳裡面的 `README.md`、`docs` 與 `checks`，然後提交。不要只上傳 ZIP，也不要額外多包一層資料夾。
3. 開啟儲存庫「Settings → Pages」。
4. Source 選擇「Deploy from a branch」，分支選 `main`，資料夾選 `/docs`，再按 Save。若預設分支不是 main，改選實際分支。
5. 等待部署完成，使用 Pages 設定頁顯示的網址開啟網站。

所有網站素材均使用相對路徑，可在專案子路徑下使用。網站不需要安裝套件、建置或 API 金鑰。Node.js 僅供執行檢查程式。

官方說明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

上傳後請確認 Logo 正常顯示，並使用「帶入範例」確認 30,000 元給付顯示實領 26,367 元，再檢查放大單據預覽。正式列印前須替換所有範例資料。
